## Project Overview
This program will provide a Task Scheduler that allows users to create tasks,mark tasks as completed or not completed and give tasks an importance level to help them arrange their work.

## Target Users
- A single user who runs this program on their computer
- Highschool or University Students

## Functional Requirement
- Create tasks
- Assign importance level for tasks
- View all tasks in list
- Mark tasks as completed or not completed
- Save tasks in text files
